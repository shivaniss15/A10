## What the page does
- On a first visit, an entry form asks the visitor for a value.
- When submitted, JavaScript saves the value in a browser cookie for 30 days.
- When the page is refreshed or reopened, the saved value is displayed without the entry form.
- The visitor can choose **Change cookie value** to enter a different value.

## Files
- `index.html` — page structure
- `styles.css` — page styling
- `script.js` — sets and reads the cookie

## Test and publish
1. Open the website over HTTPS (GitHub Pages provides HTTPS).
2. Enter a value and select **Save cookie**.
3. Refresh the page. The saved value should appear without the input form.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish, then test: https://shivaniss15.github.io/A10/index.html
